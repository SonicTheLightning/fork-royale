# Roadmap

The milestones below are proposed. They are not completed features.

| Stage | Goal | Exit criteria |
|---|---|---|
| 01 | Confirm game rules | Arena, movement, combat, match duration and victory conditions agreed |
| 02 | Simulation core | Stable world state, fixed timestep and event lifecycle |
| 03 | Free movement | Vector controls, acceleration, drag, speed limits and boundaries tested |
| 04 | Collision and combat | Entity collisions, projectile hits and damage tests |
| 05 | Bot protocol | Versioned observation/action schema and example bots |
| 06 | Playable interface | Headless CLI and separate graphical renderer |
| 07 | Reliability and security | Automated tests, replay validation and execution isolation design |
| 08 | Tournaments | Match runner, results and leaderboard |

A milestone should only be marked complete when code, tests and documentation are present.
